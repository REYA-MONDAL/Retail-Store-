# 🛍️ Retail Store Sales Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **Retail Store Sales Dashboard** built using **Microsoft Power BI**. The dashboard helps analyze sales performance, purchase trends, store-wise distribution, customer demographics, and sports product spending across multiple retail locations.

The goal is to convert raw retail transaction data into meaningful business insights that support strategic decision-making.

## 🎯 Business Problem

Retail businesses often struggle to answer questions like:

- Which store location generates the highest revenue?
- Which store type performs best?
- How do different age groups contribute to sports product sales?
- What is the spending trend for indoor vs outdoor sports products?
- Which locations require more attention?

This dashboard solves these challenges using interactive visualizations.

## 📈 Key Insights

- Urban stores generated the highest purchase percentage.
- Seattle and Los Angeles contributed significantly to total purchases.
- Children showed the highest spending in Indoor Sports.
- Outdoor Sports spending varied significantly across age groups.
- Store settings (Urban, Rural, Suburb) directly influenced purchasing behavior.
